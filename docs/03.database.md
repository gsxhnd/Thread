# Thread / 灰线 — 数据库设计

> 本文承接 [00.overview.md](00.overview.md) 第 4 节数据模型，给出 SQLite 的完整表结构、索引、迁移方案与细化 ER 图。存储方案见 [01.tech-stack.md](01.tech-stack.md)（`tauri-plugin-sql` + SQLite）。

---

## 1. 通用约定

- **主键**：统一使用 `TEXT` 存储 UUID（v4/v7），便于将来云同步去中心化生成。
- **时间戳**：`created_at` / `updated_at` 使用毫秒 Unix 时间戳（`INTEGER`）。
- **软删除**：`deleted_at`（`INTEGER`，可空），非空即视为已删除，查询默认过滤。
- **排序**：需要手动排序的实体使用 `sort_order`（`INTEGER`）。
- **正文存储**：章节正文以 **Markdown 文本** 存于 `chapters.content`。
- **外键**：开启 `PRAGMA foreign_keys = ON;`，关联删除以应用层软删除为主，物理外键用 `ON DELETE CASCADE` 仅用于纯关联表。

## 2. 表结构 DDL

### 2.1 项目与正文

```sql
-- 项目：一部作品的根容器
CREATE TABLE projects (
    id          TEXT PRIMARY KEY,
    title       TEXT NOT NULL,
    synopsis    TEXT,
    author      TEXT,
    cover_path  TEXT,
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL,
    deleted_at  INTEGER
);

-- 卷：隶属项目
CREATE TABLE volumes (
    id          TEXT PRIMARY KEY,
    project_id  TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    title       TEXT NOT NULL,
    sort_order  INTEGER NOT NULL DEFAULT 0,
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL,
    deleted_at  INTEGER
);

-- 章节：隶属卷，正文以 Markdown 存储
CREATE TABLE chapters (
    id          TEXT PRIMARY KEY,
    volume_id   TEXT NOT NULL REFERENCES volumes(id) ON DELETE CASCADE,
    project_id  TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    title       TEXT NOT NULL,
    content     TEXT NOT NULL DEFAULT '',      -- Markdown 正文
    summary     TEXT,                          -- 章节梗概（大纲用）
    word_count  INTEGER NOT NULL DEFAULT 0,
    status      TEXT NOT NULL DEFAULT 'draft', -- draft | done
    sort_order  INTEGER NOT NULL DEFAULT 0,
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL,
    deleted_at  INTEGER
);
```

### 2.2 大纲 / 剧情线

```sql
-- 剧情线：并行 plotline
CREATE TABLE plotlines (
    id          TEXT PRIMARY KEY,
    project_id  TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    name        TEXT NOT NULL,
    color       TEXT,                          -- UI 标识色
    description TEXT,
    sort_order  INTEGER NOT NULL DEFAULT 0,
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL,
    deleted_at  INTEGER
);

-- 章节与剧情线的多对多关联
CREATE TABLE chapter_plotlines (
    chapter_id  TEXT NOT NULL REFERENCES chapters(id) ON DELETE CASCADE,
    plotline_id TEXT NOT NULL REFERENCES plotlines(id) ON DELETE CASCADE,
    PRIMARY KEY (chapter_id, plotline_id)
);
```

### 2.3 人物

```sql
CREATE TABLE characters (
    id          TEXT PRIMARY KEY,
    project_id  TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    name        TEXT NOT NULL,
    alias       TEXT,                          -- 别名/尊称
    avatar_path TEXT,
    bio         TEXT,                          -- 简介（Markdown）
    attributes  TEXT,                          -- JSON: 自定义属性键值
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL,
    deleted_at  INTEGER
);

-- 人物关系：多对多，带关系类型（有向）
CREATE TABLE character_relations (
    id            TEXT PRIMARY KEY,
    project_id    TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    from_char_id  TEXT NOT NULL REFERENCES characters(id) ON DELETE CASCADE,
    to_char_id    TEXT NOT NULL REFERENCES characters(id) ON DELETE CASCADE,
    relation_type TEXT NOT NULL,               -- 如 父子/师徒/敌对
    description   TEXT,
    created_at    INTEGER NOT NULL,
    updated_at    INTEGER NOT NULL,
    deleted_at    INTEGER
);
```

### 2.4 世界观词条（地点 / 势力 / 物品）

```sql
CREATE TABLE locations (
    id          TEXT PRIMARY KEY,
    project_id  TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    name        TEXT NOT NULL,
    description TEXT,                           -- Markdown
    parent_id   TEXT REFERENCES locations(id),  -- 层级：大陆>国>城
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL,
    deleted_at  INTEGER
);

CREATE TABLE factions (
    id          TEXT PRIMARY KEY,
    project_id  TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    name        TEXT NOT NULL,
    description TEXT,
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL,
    deleted_at  INTEGER
);

CREATE TABLE items (
    id          TEXT PRIMARY KEY,
    project_id  TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    name        TEXT NOT NULL,
    description TEXT,
    created_at  INTEGER NOT NULL,
    updated_at  INTEGER NOT NULL,
    deleted_at  INTEGER
);
```

### 2.5 时间线

```sql
CREATE TABLE timeline_events (
    id           TEXT PRIMARY KEY,
    project_id   TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    title        TEXT NOT NULL,
    description  TEXT,
    story_time   TEXT,                          -- 故事内时间（自由文本，如「元武三年·春」）
    sort_key     INTEGER NOT NULL DEFAULT 0,    -- 用于时间轴排序
    created_at   INTEGER NOT NULL,
    updated_at   INTEGER NOT NULL,
    deleted_at   INTEGER
);

-- 事件与其他实体（章节/人物/地点）的通用关联
CREATE TABLE event_links (
    id          TEXT PRIMARY KEY,
    event_id    TEXT NOT NULL REFERENCES timeline_events(id) ON DELETE CASCADE,
    entity_type TEXT NOT NULL,                  -- chapter | character | location
    entity_id   TEXT NOT NULL,
    created_at  INTEGER NOT NULL
);
```

### 2.6 伏笔 · 灰线（核心）

```sql
CREATE TABLE foreshadowings (
    id                 TEXT PRIMARY KEY,
    project_id         TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    title              TEXT NOT NULL,
    description        TEXT,
    status             TEXT NOT NULL DEFAULT 'planted', -- planted | resolved
    setup_chapter_id   TEXT REFERENCES chapters(id),    -- 埋设点
    payoff_chapter_id  TEXT REFERENCES chapters(id),    -- 呼应点
    importance         INTEGER NOT NULL DEFAULT 0,      -- 重要度 0-3
    created_at         INTEGER NOT NULL,
    updated_at         INTEGER NOT NULL,
    deleted_at         INTEGER
);
```

> 状态语义：仅有 `setup_chapter_id` → `planted`（未回收）；`setup` 与 `payoff` 均存在 → `resolved`。未回收伏笔用于侧栏与统计的高亮提醒。

### 2.7 写作统计

```sql
CREATE TABLE writing_sessions (
    id           TEXT PRIMARY KEY,
    project_id   TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    chapter_id   TEXT REFERENCES chapters(id) ON DELETE SET NULL,
    date         TEXT NOT NULL,                 -- YYYY-MM-DD（本地时区）
    words_added  INTEGER NOT NULL DEFAULT 0,    -- 净增字数
    duration_ms  INTEGER NOT NULL DEFAULT 0,    -- 写作时长
    created_at   INTEGER NOT NULL
);
```

### 2.8 标签（多态）

```sql
CREATE TABLE tags (
    id          TEXT PRIMARY KEY,
    project_id  TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    name        TEXT NOT NULL,
    color       TEXT,
    created_at  INTEGER NOT NULL,
    UNIQUE (project_id, name)
);

-- 标签与任意实体的关联
CREATE TABLE entity_tags (
    tag_id      TEXT NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
    entity_type TEXT NOT NULL,                  -- chapter | character | location | ...
    entity_id   TEXT NOT NULL,
    PRIMARY KEY (tag_id, entity_type, entity_id)
);
```

## 3. 索引

```sql
-- 常用外键与列表查询索引
CREATE INDEX idx_volumes_project     ON volumes(project_id);
CREATE INDEX idx_chapters_volume     ON chapters(volume_id);
CREATE INDEX idx_chapters_project    ON chapters(project_id);
CREATE INDEX idx_plotlines_project   ON plotlines(project_id);
CREATE INDEX idx_characters_project  ON characters(project_id);
CREATE INDEX idx_relations_from      ON character_relations(from_char_id);
CREATE INDEX idx_relations_to        ON character_relations(to_char_id);
CREATE INDEX idx_locations_project   ON locations(project_id);
CREATE INDEX idx_factions_project    ON factions(project_id);
CREATE INDEX idx_items_project       ON items(project_id);
CREATE INDEX idx_events_project      ON timeline_events(project_id);
CREATE INDEX idx_event_links_event   ON event_links(event_id);
CREATE INDEX idx_event_links_entity  ON event_links(entity_type, entity_id);
CREATE INDEX idx_foreshadow_project  ON foreshadowings(project_id);
CREATE INDEX idx_foreshadow_status   ON foreshadowings(status);
CREATE INDEX idx_sessions_project    ON writing_sessions(project_id);
CREATE INDEX idx_sessions_date       ON writing_sessions(date);
CREATE INDEX idx_entity_tags_entity  ON entity_tags(entity_type, entity_id);
```

> 全文检索（章节正文）可在后续引入 SQLite **FTS5** 虚拟表 `chapters_fts`，通过触发器同步 `chapters.content`。首版可暂用 `LIKE` 简单检索。

## 4. 迁移方案

使用 `tauri-plugin-sql` 的 migrations 机制，在 Rust 侧注册版本化 SQL：

```rust
// src-tauri/src/db/migrations.rs（示意）
use tauri_plugin_sql::{Migration, MigrationKind};

pub fn migrations() -> Vec<Migration> {
    vec![
        Migration {
            version: 1,
            description: "init schema",
            sql: include_str!("../../migrations/0001_init.sql"),
            kind: MigrationKind::Up,
        },
        // 后续新增：version: 2, 0002_add_fts.sql ...
    ]
}
```

- SQL 文件按 `migrations/000N_*.sql` 顺序编号，**只增不改**（已发布的迁移不可修改）。
- 每次结构变更新增一个迁移文件并递增 `version`。
- 目录约定见 [01.tech-stack.md](01.tech-stack.md) 与 [06.dev-guide.md](06.dev-guide.md)。

## 6. 云同步预留（Phase 5）

- 所有业务表均带 `updated_at` 与 `deleted_at`，为「最后写入生效」或 CRDT 合并预留。
- UUID 主键避免多端自增冲突。
- 具体同步协议在 Phase 5 另立文档。
