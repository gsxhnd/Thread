# Thread / 灰线 — IPC 接口设计

> 本文定义前端与 Rust 后端之间的 Tauri command 接口、事件与前端封装约定。承接 [02.architecture.md](02.architecture.md) 的职责边界与数据流。

---

## 1. 通用约定

### 1.1 命名

- Command 采用 `模块_动作` 蛇形命名：`chapter_save`、`foreshadowing_link`。
- 动作动词统一：`create` / `update` / `delete` / `get` / `list` / 专有动作（如 `save`、`link`、`reorder`）。

### 1.2 参数与返回

- 入参：单对象 `payload`（`serde` 反序列化），字段小驼峰（前端）↔ 蛇形（Rust）由 serde `rename_all` 处理。
- 返回：成功返回数据对象；失败返回统一错误结构。

```ts
// 统一错误结构（前端侧类型）
interface AppError {
  code: string;      // 见 §5 错误码
  message: string;   // 面向用户/日志
}
```

```rust
// Rust 侧错误（thiserror），序列化为 { code, message }
#[derive(Debug, thiserror::Error)]
pub enum AppError {
    #[error("not found: {0}")]
    NotFound(String),
    #[error("validation: {0}")]
    Validation(String),
    #[error("db error: {0}")]
    Db(String),
    #[error("ai error: {0}")]
    Ai(String),
    #[error("io error: {0}")]
    Io(String),
}
```

### 1.3 时间戳与 ID

- ID 由后端生成 UUID 返回；`created_at` / `updated_at` 后端写入。
- 分页统一 `{ limit, offset }`，列表返回 `{ items, total }`。

## 3. 事件 Emit

后端向前端推送的异步事件，前端在 `src/lib/api/events.ts` 统一订阅：

| 事件名 | payload | 用途 |
| --- | --- | --- |
| `chapter://saved` | `{ chapterId, savedAt, wordCount }` | autosave 状态指示 |
| `ai://chunk` | `{ requestId, delta }` | AI 流式增量 |
| `ai://done` | `{ requestId, finishReason }` | AI 完成 |
| `ai://error` | `{ requestId, code, message }` | AI 出错 |
| `export://progress` | `{ taskId, percent }` | 导出进度 |

## 4. 前端 IPC 封装约定

- 所有 command 封装在 `src/lib/api/*.ts`，按模块拆分（`project.ts`、`chapter.ts`、`foreshadowing.ts`、`ai.ts` ...）。
- **禁止** 在组件中直接调用 `invoke`；组件只调用 typed wrapper。
- 类型定义集中在 `src/lib/api/types.ts`，与 Rust 结构一一对应。

```ts
// src/lib/api/chapter.ts（示意）
import { invoke } from "@tauri-apps/api/core";
import type { Chapter } from "./types";

export function chapterSave(input: {
  id: string;
  content: string;
  title?: string;
}): Promise<{ savedAt: number; wordCount: number }> {
  return invoke("chapter_save", { payload: input });
}

export function chapterGet(id: string): Promise<Chapter> {
  return invoke("chapter_get", { payload: { id } });
}
```

```ts
// src/lib/api/events.ts（示意）
import { listen } from "@tauri-apps/api/event";

export function onChapterSaved(
  cb: (p: { chapterId: string; savedAt: number; wordCount: number }) => void,
) {
  return listen("chapter://saved", (e) => cb(e.payload as any));
}
```

配合 TanStack Query 时，写操作成功后按实体 key 失效缓存（如 `["chapterTree", projectId]`）。

## 5. 错误码约定

| code | 含义 | 前端处理 |
| --- | --- | --- |
| `NOT_FOUND` | 资源不存在 | toast 提示，刷新列表 |
| `VALIDATION` | 参数校验失败 | 表单内联报错 |
| `DB_ERROR` | 数据库错误 | toast + 可重试 |
| `AI_ERROR` | AI 调用失败 | AI 面板内提示 + 可重试 |
| `AI_NO_KEY` | 未配置 API Key | 引导到 AI 设置 |
| `IO_ERROR` | 文件读写失败（导出等） | toast 提示 |
