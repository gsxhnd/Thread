# Thread / 灰线 — IPC 接口设计

> 本文定义前端与 Rust 后端之间的 Tauri command 接口、事件与前端封装约定。承接 [02.architecture.md](02.architecture.md) 的职责边界与数据流。

---

## 1. 通用约定

### 1.1 命名

- Command 采用 `模块_动作` 蛇形命名：`http_send`、`proxy_start`。
- 动作动词统一：`create` / `update` / `delete` / `get` / `list` / 专有动作（如 `send`、`connect`、`start`、`stop`）。

### 1.2 参数与返回

- 入参：单对象 `payload`（`serde` 反序列化），字段小驼峰（前端）↔ 蛇形（Rust）由 serde `rename_all` 处理。
- 返回：成功返回数据对象；失败返回统一错误结构。

```ts
// 统一错误结构（前端侧类型）
interface AppError {
  code: string;      // 见 §6 错误码
  message: string;   // 面向用户/日志
}
```

```rust
// Rust 侧错误（thiserror），序列化为 { code, message }
#[derive(Debug, thiserror::Error)]
pub enum AppError {
    #[error("not found: {0}")]
    NotFound(String),
    #[error("validation: {0}")]
    Validation(String),
    #[error("db error: {0}")]
    Db(String),
    #[error("network error: {0}")]
    Network(String),
    #[error("proxy error: {0}")]
    Proxy(String),
    #[error("tls error: {0}")]
    Tls(String),
    #[error("timeout: {0}")]
    Timeout(String),
    #[error("io error: {0}")]
    Io(String),
    #[error("proto error: {0}")]
    Proto(String),
}
```

### 1.3 时间戳与 ID

- ID 由后端生成 UUID 返回；`created_at` / `updated_at` 后端写入。
- 分页统一 `{ limit, offset }`，列表返回 `{ items, total }`。

### 3.2 历史 History

每次发送自动入库：**请求内容 + 响应内容**均需可还原（见 [00.overview.md](00.overview.md) §2.4）。列表接口返回摘要；详情接口返回双端完整快照（含 Body 内联或文件引用）。

| Command | 入参 | 返回 | 说明 |
| --- | --- | --- | --- |
| `history_list` | `{ workspaceId, protocol?, limit?, offset? }` | `{ items: HistorySummary[], total }` | 分页；摘要含方法/URL/状态码/耗时，不含大体 |
| `history_get` | `{ id }` | `HistoryEntry` | **请求快照 + 响应快照**（含 Body） |
| `history_delete` | `{ id }` | `void` | 同步删除关联 body 文件 |
| `history_clear` | `{ workspaceId, beforeTimestamp? }` | `{ deletedCount }` | 批量清理 |
| `history_save_to_collection` | `{ historyId, collectionId, name? }` | `Request` | 用**历史中的请求快照**另存为集合请求 |
| `history_replay` | `{ id }` | `HttpResponse`（或协议对应类型） | 按历史请求快照重发（非集合文件） |

```ts
// HistoryEntry（示意）
interface HistoryEntry {
  id: string;
  workspacePath: string;
  protocol: string;
  name?: string;
  // 列表字段
  url: string;
  method?: string;
  statusCode?: number;
  durationMs?: number;
  createdAt: number;
  errorMessage?: string;
  // 双端完整内容
  requestSnapshot: RequestSnapshot;   // 实际发出的请求（含 body）
  responseSnapshot?: ResponseSnapshot; // 完整响应（含 body / timing）
  requestBodyPath?: string;
  responseBodyPath?: string;
}
```

## 5. 事件 Emit

后端向前端推送的异步事件，前端在 `src/lib/api/events.ts` 统一订阅：

### 5.1 请求相关

| 事件名 | payload | 用途 |
| --- | --- | --- |
| `http://progress` | `{ taskId, downloadedBytes, totalBytes? }` | 下载进度 |
| `grpc://stream` | `{ streamId, data, index }` | gRPC streaming 数据 |
| `grpc://stream_end` | `{ streamId, status }` | gRPC streaming 结束 |

### 5.2 长连接相关

| 事件名 | payload | 用途 |
| --- | --- | --- |
| `ws://message` | `{ connectionId, data, isBinary, timestamp }` | WebSocket 收到消息 |
| `ws://status` | `{ connectionId, status, reason? }` | WebSocket 状态变化（connected/disconnected/error） |
| `mqtt://message` | `{ connectionId, topic, payload, qos, timestamp }` | MQTT 收到消息 |
| `mqtt://status` | `{ connectionId, status, reason? }` | MQTT 状态变化 |
| `graphql://subscription` | `{ subscriptionId, data }` | GraphQL Subscription 数据 |

### 5.3 代理相关

| 事件名 | payload | 用途 |
| --- | --- | --- |
| `proxy://entry` | `ProxyEntrySummary` | 新捕获的请求/响应摘要 |
| `proxy://breakpoint` | `{ breakpointId, request }` | 命中断点，等待用户操作 |
| `proxy://status` | `{ running, sessionId?, error? }` | 代理引擎状态变化 |

## 6. 前端 IPC 封装约定

- 所有 command 封装在 `src/lib/api/*.ts`，按模块拆分：
  - `collection.ts` — 集合管理
  - `request.ts` — 请求 CRUD
  - `http.ts` — HTTP 发送
  - `grpc.ts` — gRPC 操作
  - `websocket.ts` — WebSocket 管理
  - `graphql.ts` — GraphQL 操作
  - `mqtt.ts` — MQTT 操作
  - `environment.ts` — 环境变量
  - `history.ts` — 历史记录
  - `proxy.ts` — 代理控制
  - `certificate.ts` — 证书管理
  - `events.ts` — 事件订阅
- **禁止** 在组件中直接调用 `invoke`；组件只调用 typed wrapper。
- 类型定义集中在 `src/lib/api/types.ts`，与 Rust 结构一一对应。

```ts
// src/lib/api/http.ts（示意）
import { invoke } from "@tauri-apps/api/core";
import type { HttpResponse, HttpRequestConfig } from "./types";

export function httpSend(input: {
  requestId?: string;
  config: HttpRequestConfig;
  environmentId?: string;
}): Promise<HttpResponse> {
  return invoke("http_send", { payload: input });
}

export function httpCancel(taskId: string): Promise<void> {
  return invoke("http_cancel", { payload: { taskId } });
}
```

```ts
// src/lib/api/events.ts（示意）
import { listen } from "@tauri-apps/api/event";

export function onWsMessage(
  cb: (p: { connectionId: string; data: string; isBinary: boolean; timestamp: number }) => void,
) {
  return listen("ws://message", (e) => cb(e.payload as any));
}

export function onProxyEntry(
  cb: (p: ProxyEntrySummary) => void,
) {
  return listen("proxy://entry", (e) => cb(e.payload as any));
}
```

配合 TanStack Query 时，写操作成功后按实体 key 失效缓存（如 `["collections", workspaceId]`）。

## 7. 错误码约定

| code | 含义 | 前端处理 |
| --- | --- | --- |
| `NOT_FOUND` | 资源不存在 | toast 提示，刷新列表 |
| `VALIDATION` | 参数校验失败 | 表单内联报错 |
| `DB_ERROR` | 数据库错误 | toast + 可重试 |
| `NETWORK_ERROR` | 网络不可达/连接拒绝 | 响应面板内展示 |
| `TIMEOUT` | 请求超时 | 响应面板内展示 + 可重试 |
| `TLS_ERROR` | TLS 握手失败/证书错误 | 响应面板内展示详情 |
| `PROXY_ERROR` | 代理引擎错误 | 代理面板提示 |
| `PROTO_ERROR` | Proto 文件解析失败 | gRPC 面板提示 |
| `IO_ERROR` | 文件读写失败 | toast 提示 |
| `CANCELLED` | 用户取消 | 静默处理 |
